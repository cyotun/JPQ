# 记牌器BETA C4.3：一级设置内完成更新

2026-10-24，按用户要求删除应用更新二级页面。设置首页「应用更新」左侧显示状态，最右侧只保留一个金色按钮，按检查、下载、进度、安装状态切换。整行不跳转；非 Wi-Fi 下载确认和系统安装授权继续保留。视觉和状态表见 [更新行规格](../design/inline-updates.md)。

## 实现与复查

- 页面只读显示缓存，不在界面线程验签、读完整 APK、等待下载锁或联网。检查、下载、缓存复核和安装校验继续后台执行；退出或暂停设置页停止进度轮询。
- 下载失效、安装校验失败后回到「检查更新」；检查确认相同的已下载包仍然有效时直接显示「安装」。状态缓存只决定按钮，执行动作时仍验证签名、版本、包名、哈希和安装身份。
- 新通知打开一级设置。旧通知和保存状态中的 `page=update` 映射到设置；应用已打开时收到旧通知也一样。返回键直接回到记牌首页。
- 正在记牌时禁止手动更新操作。BETA 没有独立更新通道，按钮显示 BETA 并禁用，不能借此获取或安装正式包。
- Luna 独立复查发现下载地址失效后的缓存复核可能清除重新检查标志，已修复；主代理复核了最终代码和测试。
