# 0.2.11 离线尾局修复与界面调整

2026-10-14。用户暂时无法连接手机。本轮仅离线分析附件与既有录像，构建候选；没有安装、操作手机或发布稳定更新。

## 附件故障与修复

附件 `记牌器测试日志.zip` 128042273 bytes，ZIP CRC检查通过。最新五会话包含五个独立失败牌局。根因不是可以忽略的容量检查：

- 对手双上：PREVIOUS与NEXT已各出27，自己和队友仍有牌，结算展示被当成桌面出牌/无法归属。确认任一同队双方都出完或三人出完后，同一帧归档并等待下局，不再读取结算余牌为出牌。最终真实出牌必须先正常确认；一名对手还差1张、两个不同队玩家出完时仍继续。
- 高叠手牌连接到桌面：手牌顶部与中央出牌的间隔很短，当前连接规则把较小的桌面字形吸进手牌列，拆散自己的最后一手。新增顶部连接字形尺度约束，保留真实高叠/选中抬牌/王的兼容。中央完整末手恢复后，通过已有精确点数/红黑与几何证据维护ownExit，不补猜漏掉的牌。
- 例：0750会话自己的最后一手实际A黑2+A红1+9红2。一张9被接到队友J顶行后，四张残组被误归上家，A黑消耗4→6、9红4→5，容量冲突确实应拒绝。修复归属，保留容量/置信度/去重约束。
- 最新末局诊断画面独立可见队友仍有8张，仍在接风，不能按自己出完判整局结束。其余旧故障对应JPEG已被100MiB轮转删除，仅日志几何证据，不能冒充逐张图像真值。

新日志将记录selfFinished、passing和完成/队友文字的OCR框位置，以便下一轮直接复核原始观察。旧附件没有这些字段，回放selfFinished部分取自旧ledger phase，不完整复现实时OCR。

## 已实现的界面要求

1. 首页固定一页：腾讯大掼蛋/玩法/4人2副的摘要、牌容量、状态及固定主按钮；首页没有ScrollView，其他设置页面保留滚动。
2. 同一个主按钮按实际运行状态显示开始/停止，删除返回记牌和重复停止行。
3. 三家出牌显示：隐藏、仅数量、数量和详情。仅数量保留上/对/下与金色累计出牌数，32dp两列，不留详情宽度；旧配置/备份默认兼容旧全显示或全隐藏。
4. 最近牌局、导出诊断、诊断画面开关、清理功能移至设置→牌局与诊断。
5. 权限入口只留设置。开始缺悬浮权限时引导进入权限，返回进入来源；返回来源保存跨页面重建。
7. 停止保存最后游戏位置；拖动实时保存。x/y迁移为屏幕左上角比例，尺寸/隐藏不改变位置基准。临时回到竖屏APP限位不覆盖横屏游戏位置；仅启动竖屏后直接停止不覆盖历史位置。

第6项是[独立同花顺设计](../design/straight-flush/README.md)，仍未接入正式APP。用户选牌格旁位置、不要中文，否定五张牌图案后修订为单个12dp小黑桃。亮表示天然或含变牌仍可能，暗表示全部排除，未知暂不显示。当前检测模型仅有点数/红黑类别；正式开发仍需花色读取和有效级牌/变牌规则确认，不能用亮暗设计代替识别实现。
