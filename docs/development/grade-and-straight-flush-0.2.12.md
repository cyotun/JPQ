# 0.2.12：级牌读取、同花顺和遮挡提示

2026-10-14。用户确认提示效果图后完成离线开发。此为回归测试包，未发布为Cloudflare稳定更新，本轮没有连接、安装或操作手机。

## 行为

- 同花顺图标沿用确认的12dp小黑桃、16dp灰牌格槽。亮表示当前计算范围未排除，暗表示已排除；不表示某一家确定持有。
- 级牌取自本局公告、左上角与实际牌角证据，三次独立新证据、至少500ms后确认。本局公告优先于两队升级进度，随机级牌不会被后续较弱HUD读数覆盖；不同级数不能直接假设都是逢人配。冲突撤回，遮挡保留已确认级牌，新局/会话重新读取。
- 未获取完整有效级牌时，仅判断天然同花顺，不显示未识别提示。桌面变牌可能是逻辑替代牌，此时保留相应自然牌恢复的不确定性，不猜物理来源、不误扣精确花色；图标可能较晚变暗。
- 遮挡级牌区时显示确认的小号黑金提示与「一键挪开／忽略」，APP设置可关闭。忽略属于本次记牌，会跨局、区域变化和设置切换持续，停止后重新开始恢复。隐藏记牌条时不显示提示。
- 一键只选择能放下完整记牌条的顶部位置，避开级牌与规则HUD；没有安全位置时提示手动拖动，不把窗口放到出牌区。移动保存位置，不改账本、不重启本局。
- 提示使用独立窗口与紧致遮罩，首次可见前先建立目标遮罩，布局后改用实际坐标；不把透明区域当成遮挡，不暂停记牌。提示限制在屏幕左侧40%和顶部24%内，过窄或无法安全放置时不覆盖牌局。
- 花色分别记录为黑桃、红桃、梅花、方块；弱证据保留红黑约束。开局快速出牌导致初始花色尚未完成时，用稳定当前本人手牌与自身已提交出牌重构原始27张，仅补充花色，不重复扣自己的牌。自己出完后不以队友展示手牌重构本人基线，三家记录继续。
- 级牌/花色分析独立于主记牌提交，缓存接受过的证据，清除跨可见性间隔的候选票。过期轮次、已停止会话、不同画面周期及改变过的出牌快照不能提交后台结果。级牌分析异常仅撤回此元数据，不使主账本退出记牌。
