# 第一批 Android 基础开发记录

2026-10-11。用户已整体确认现稿并要求开始开发，随后要求继续主要参考原 APK，暂不强求连接手机。本轮已建立自研 Android 工程和记账核心，不复制原 APK 工程、模型或原生库。

## 当前完成

- 项目内可复现构建环境、固定依赖、Gradle wrapper 和发行包 SHA-256 校验。
- 「记牌器」首页/设置、权限引导、系统共享授权、前台采集服务、最新帧处理、尺寸变化及停止释放。
- 原字体/色值的 Canvas 悬浮条、金色等待提示、隐藏/显示、重置显示开关、可选双击隐藏、拖动与长按工具。
- 横屏尺寸/牌序调整、四列八项配置、两行牌面拖动、退出不保存、保存配置、旋转保留草稿。调整页使用与实际悬浮窗相同的绘制器，示例不进入实际账本。
- 基础右侧宽度、超长扩展、保留左侧锚点、屏幕边界、不同按钮组合、手势期间延迟几何更新。
- 物理牌库容量、固定初始手牌、自己出牌不重复扣除、稳定帧去重/新边界重复牌、异常未知显示与玩法牌序。
- 配置导入/导出、系统自动备份排除、开发包名/签名隔离、1 号图标及单色资源、服务版本检查入口。

上述为代码实现与构建结果，**不表示已经通过手机交互或真实牌局测试**。

## 实际验证

构建命令为 `tools/android/build.ps1`：核心单元测试、开发 APK 编译与 Android lint。实际机器的环境准备和首次构建曾暴露新版 SDK 包名、返回手势与 Kotlin 类型错误，均已修正；没有忽略 lint 错误或把失败当作通过。

- 核心 10 项测试通过，0 错误/0 失败。覆盖自己不重复扣、重复显示与后续同牌再出、物理容量、跨局/不足 27 张、队友展示、不可恢复、配色/牌序、重复初始化、自动扩展/新局恢复和手动尺寸变化。
- 开发包成功构建，Android lint 0 错误；仍有 21 项警告，以绘制对象分配、版本建议、KTX/文本/图标等提醒为主，后续结合手机测量处理，不宣称无警告。
- APK 安装签名已通过 `apksigner verify`，包名/版本/最低 API/目标 API 经 `aapt dump badging` 检查。
- 仅存在本机基础调试包，未上传 Cloudflare、未发布 GitHub Release、未使用正式签名。开发包为 `com.cyotun.jpq.dev`，正式包为未来的 `com.cyotun.jpq`。
- 未连接手机、未运行模拟器。没有 Android 启动/授权/触摸实测或识别准确率结果。ADB 在默认受限环境中未能启动，未将其视为“手机已验证”或读取其他设备。

APK 大小、实际 SHA-256 和检查数量保存在 [验证快照](foundation-verification.json)。源码构建输出位于 `app/build/outputs/apk/debug/app-debug.apk`，个人验证副本保存在本机 `artifacts/记牌器-0.1.0-基础开发版.apk`；输出与私有字体/签名文件均被 Git 排除。
