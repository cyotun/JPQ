# 0.2.22：确认后的计数事务与局部花色撤销

日期：2026-10-18。测试版 `0.2.22-regression` / code24。

## 显示语义

用户要求在识别复核期间保留最后确认的数字，识别确认后再扣减，取消用问号表示处理中间状态。

新增 `GradeCounterPresentation`，与原始物理牌推断、点数账本分离：

- 同一局、同一级牌下，心形逢人配与所有普通级牌计数作为一个事务发布。只要其中一项仍是上下界，继续展示上一次完整确认的事务，全部成为精确计数后一起更新。
- 原始 `GradeCounterState` 仍保存本次出牌的真实上下界和原因。显示缓存不会反向进入牌数、花色、逢人配或同花顺计算，不会把旧显示数伪装成本次识别证据。
- 新局、级牌集合变化、停止以及物理证据硬冲突清除旧事务，防止沿用另一局数据。首次尚无确认值时不编造默认计数，数字格留空。
- 记牌条不再用 `?` 绘制待确认数字。正常其他点数仍由已确认的点数账本提供；本改动不把未经确认的检测结果直接扣入账本。
