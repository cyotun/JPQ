# 0.2.9 末段和队友视角回归

日期：2026-10-14。手机 Xiaomi 2509FPN0BC、Android 17，腾讯大掼蛋 3.2.1。当前仍为回归候选，不发布稳定更新。

## 真实日志定位与修复

0.2.5 用户测试日志的五类首次失败，均没有在失败前十秒观察到悬浮遮挡或丢帧长间隔。移除长按设置满足交互要求，但不能单独解释这些停止记牌的问题。

- 桌面牌与上叠手牌之间较大的空隙被误当作同一手牌列。将上叠连接空隙限制由 glyph 高度 1.5 倍改为 0.6 倍，保留紧密叠牌，避免吸走自己中央出的 Q/5。
- 自己和队友均已出完时，敌方剩余手牌展示被当作新出牌。完整累计证据证明两名队友出完，或已有三人出完时，先结束旧局并清除候选。自己先完但队友未完时继续记录。
- 已有牌组扩展遇到短暂颜色/分数摇摆。已知牌组的逐 glyph 几何关联可在最多 1500ms 内恢复；新牌仍要求至少 .65 置信度及四帧确认。不可观察区域连续超过 500ms 会清除扩展几何证据，不能借放宽窗口跨越盲区合并出牌。
- 自己最后一手在队友视角中返回，无法归属。新增只记录展示归属的 OwnExitPresentationTracker；完整牌色多重集、逐 glyph 几何、短时间连续性共同确认，空区两次正证据、新局/终局及超时清除。它不提交猜测牌数，不迁移同牌不同位置的展示。

新导出的 0.2.8 实际会话包含 3808 个 frame 记录。第二局自己最后剩 K黑×3＋K红，中央两帧完整识别时，底部已替换成队友 24 张手牌，但 OCR 暂时仍是 TABLE。旧退出候选要求底部手牌为空，因而未建立关联。随后两帧颜色抖动恢复后仍持续 ambiguous，导致停止。

现在完整中央牌组等于旧自身剩余手牌、底部为空或已不是旧手牌子集时，可以建立退出展示候选；不要求先出现队友文字。正确颜色在 1063ms 后返回，现有严格颜色/几何窗口足够恢复。没有放宽成同 rank 异色也直接忽略。

SELF_FINISHED 状态下 OCR 短暂回落 TABLE，继续按 TEAMMATE 分区处理；RESULT、DEALING、TRIBUTE、LOBBY、UNKNOWN 仍按各自边界处理。队友展示的底部手牌不作为新出牌或自身初始手牌。

## 速度优化与手机采集

V4 的未覆盖纸面保护会把桌面按钮的薄白字当作灰白牌纸，频繁回退整图。原图检查确认这些 18–46 点的小文字没有 3×3 实心中性支持；小王的灰纸面和动画附近部分中性区域有支持。候选优化在扣除 tile 前的完整组件判断支持，再保留 tile 外原 16 点、4×6 残块保护；大型轮廓仍保守回退。核心在 tile 内、外侧只剩小尾部的边界必须回退。

此像素规则仅决定是否用当前整图复核，不识别牌点或牌数。严重遮挡、不同主题或尺寸的覆盖仍需实际连续验证；静态小王和完整 2805 帧手机回放通过后才能选择该快速路径。

本机快速路径仍用 Build.FINGERPRINT 和管线版本显式选择。手机工具写开关只是操作，不是准确性认证。PhoneCaptureUiDriver 临时替换已有测试包、以测试包自身为 target，仅点击本应用开始/停止按钮及对应系统标准屏幕共享确认；结束工具不终止记牌器进程，禁止点击游戏。正常测试 APK 随后恢复。
