## 项目是什么、目前做到哪里

这是一个本地识别屏幕上已显示牌面的 Android 记牌 APP，当前支持腾讯独立 APP「大掼蛋」的默认掼蛋、四人、两副牌（108 张）。不读取游戏网络协议或未显示的对手手牌，不依赖云端识别。保留多游戏扩展结构，但其他组合尚未开放；不能因存在选择项而视为已经适配。

用户在首页选平台/玩法后开始记牌，经过 Android 系统共享授权，到游戏建立合格开局基线。后台识别自己初手、三家已出牌、级牌和花色，账本确认后更新悬浮条。自己初手从三家未知池扣除；自己的后续出牌不再重复扣未知池。自己出完后继续记，确认展示的队友余牌后再剔除，使未知池只含对手。整局结束与自己出完分别判定。

现有产品功能包括黑金单页首页、开始/停止、设置单一权限入口、悬浮条尺寸/字号/牌序、三家记录三种显示模式、可隐藏重置、双击隐藏、可拖动「显示」按钮、位置记忆、级牌角标与独立 ♥逢人配、同花顺图案和金色候选点数、本地诊断二级菜单、配置备份和正式应用内更新。交互细节与配色以当前规格和实现为准，不从头改版。

数据处理主线为 `CaptureService → TencentRecognizer → RoundObserver → RoundLedger → 余牌/同花顺分析 → 确认显示缓存 → OverlayController`。界面和配置在 `MainActivity` / `ConfigStore`，牌局保存在本机 `RoundRepository`，诊断由本机 `SessionTrace` 等组件记录。Cloudflare 只分发签名更新，不接收牌局数据。

本次已将单应用采集和 BETA 累积的恢复修复提升到正式版，并修复能力开关误关正式更新的风险。暂时的动画或弱读保持最近确认数字，后台取证后再提交；真实缺失的历史不得猜补。源码入口和具体不变量见架构及恢复约束文档。

## 源码与身份

纯逻辑在 `core/`，Android 界面、采集、识别、诊断和更新在 `app/`，更新服务在 `services/updates/`。正式包名 `com.cyotun.jpq`、BETA 包名 `com.cyotun.jpq.candidate` 不变；显示名分别为「记牌器」「记牌器BETA」。

本轮开发分支归档为 `archive/beta-through-0.2.27` 后删除。后续新功能仍在临时 BETA 分支开发、review 和验证，明确验收后再提升正式版；本轮豁免不自动适用于未来发布。不得因为删除分支而卸载手机应用或清空应用数据。

`SINGLE_APP_CAPTURE_ENABLED` 控制已提升的采集/恢复能力；`SINGLE_APP_CAPTURE_CANDIDATE` 只控制 BETA 身份、更新隔离及实验入口。API 37+ 使用系统单应用授权，旧系统使用 DISPLAY；整屏输入的遮挡不可凭空恢复。当前完整 CPU 识别路径不继承旧 reference 资格，尚无本轮新增功耗实测结论。
