# 单应用采集与低风险降耗候选

基于 `v0.2.26` / `ea5568147ecd24b59120a03360fcb4cd4248d01d`，分支 `codex/single-app-capture-power`。稳定版本说明不变，研究依据见 [研究记录](../research/single-app-capture-and-power-20261019.md)。本轮不启用 GPU/NPU、不改变采样周期/模型分辨率/记账阈值、不发布稳定更新。

## 回滚保护

| 项目 | 稳定 | 候选 |
| --- | --- | --- |
| 包名 | `com.cyotun.jpq` | `com.cyotun.jpq.candidate` |
| 桌面名 | 记牌器 | 记牌器·候选 |
| 本机数据 | 原配置与牌局保持 | 独立 SharedPreferences/SQLite/诊断 |
| 更新 | 保留原通道 | 检查、下载、安装及任务调度禁用 |

只安装 candidate 产物，不用候选分支生成的普通 Release 覆盖手机稳定版。两个应用不能同时屏幕共享；切换前先停止正在运行的共享，确认通知/悬浮窗已结束。

本机 `artifacts/rollback-v0.2.26/` 保存稳定 APK、原验证 JSON、完整历史 Git bundle 和回滚 manifest；私钥不打包。稳定 APK SHA-256 固定 `7033136f84a8f28b16106724c26e3651f9e156b9e5d29098fc6b413b70b8411c`，证书固定 `ebe83c802f083bdb1adafc6163744dfa2cbd30f5677c04ab5ff29356c5cff71f`。执行 `tools/android/verify-stable-rollback.ps1` 只校验文件/签名/tag，不操作手机。

使用中回退：正常结束对局 → 停止候选共享 → 打开仍在手机中的稳定记牌器 → 按原方式授权开始。无需卸载稳定应用、降低 versionCode 或清空稳定数据。候选配置若需沿用，使用已有配置导出/导入，自行保留两份；本轮不自动拷贝稳定应用私有目录。

离线恢复源码：在新目录从本机 bundle 克隆后选择 `v0.2.26`；或从 GitHub 稳定标签新建修复分支。不得直接 reset 覆盖未保存工作。模型/字体/原生库/签名身份继续按原本机备份单独保存。

## 首阶段实现

- 额外 candidate buildType，与 release 共存。默认 release/debug 保持原整屏模式；候选仅通过 Android 17/API 37 的公开 APP-only 来源配置启动。低版本或厂商缺少该公开接口时明确失败，使用稳定版，不默默退为整屏却去掉遮挡保护。
- 通过反射访问官方公开 Builder，保持 compileSdk 36 与现有 AGP/Gradle；不访问隐藏 API、不给自己签发授权。API 37 方法/字段缺失即终止本次开始。
- 单应用输入按内容真实尺寸建立 reader/resize，屏幕物理浮层矩形不再涂到游戏像素；拖动外部记牌条不再触发输入遮挡。单应用模式不显示旧级牌遮挡提示。整屏路径保留原行为。
- 原始可见性/停止回调继续处理真实共享失效；task 尺寸切换退役旧 epoch，不能将旧画面当新尺寸输入。
- 诊断关闭不构造逐帧大 JSON；同花顺持久化 metadata 和记账流程不因诊断关闭而省略。启用诊断时保留原字段，新增包名/采集范围以区分来源。

候选构建使用 `tools/android/build.ps1 -Tasks ':app:assembleCandidate',':app:testCandidateUnitTest',':app:assembleCandidateAndroidTest',':app:lintCandidate','-PjpqCandidate=true'`。候选测试包为 `com.cyotun.jpq.candidate.tests`。不能直接运行旧手机测试脚本：其中部分组件/探针仍指向稳定包，需逐项审查或使用专用候选测试。

## 验证门槛与待办

先编译、核心/宿主/候选单测、现有连续回放及 Lint，重新校验回滚包。再安装独立候选，核验 manifest/签名/更新隔离；旧稳定包版本、配置不改变。

手机先做非对局：真实大掼蛋大厅和专用测试图，独立物理图/采集图对照，确认自家条覆盖处仍有原画面；多浮窗/通知、旋转、拒绝授权、停止和最近任务移除。不得把到帧或 unit test 通过当成 task 隔离已实测。

非对局验证通过后才请用户正常打局。对局中只读本机日志，不操作游戏、不录屏/第二共享、不重启或 instrumentation。完整结束后核对物理牌/座位/末手/队友余牌/同花顺。降耗收益另作固定条件、断开充电、诊断关闭的长时对照，不由延迟直接推算节电比例。
