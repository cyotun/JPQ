# 0.2.24：己方最后一手与队友视角的交接

版本 `0.2.24-regression`，versionCode 26。只修复有直接证据的己方最后一手历史遗漏，不推断缺失出牌，也不再次扣除不可变初始己手。

## 实际问题与修复边界

0.2.23 的真实局 `42052328-1` 在 42256556–42256962 连续四个 TABLE 捕获帧完整识别最后一张红王，底部已经显示队友 12 张；42257111 首次识别到 TEAMMATE 时仍完整可见该红王。原流程先清空当前己手，再尝试普通手牌差分，造成 SELF 历史只有 26 张。外部剩牌没有错误，因为自己的初始 27 张从开局就已排除。

新增 `OwnExitPlayProof`，在清空己手之前验证：

- 同一局、同一已确认己手版本，已记 SELF 张数与当前己手总和恰好 27；候选前 500ms 内必须直接看见完整原己手。
- TABLE 阶段至少四个不同时间帧直接完整看见全部最后己手，每张置信度至少 0.8，颜色/点数多重集匹配，框有效，没有重复物理槽；几何逐张匹配不可变首锚和前帧。
- 下方手牌已明确离开原己手，null 或原己手片段不等于出完；相邻帧最多 500ms，候选总长最多 1500ms。
- 仅在明确的 TEAMMATE/selfFinished 到达时交付，当前帧仍须完整强读且匹配原槽。TEAMMATE 使用合格的 teammateHand，不把 hand=null 当作空手。
- UNKNOWN、捕获缺口、遮挡、模糊归属、恢复、原己手返回或版本改变清空候选。没有足够正面证据时保留原行为，不按完成标签制造缺牌。已进入 SELF_FINISHED 后不回填历史。

观察器在场景和 handoff 分支之前调用该证明。提交的是当前账本已经拥有的牌；任一新旧己方提交路径先成功后，阶段立即变化，另一条不能重复提交。不同捕获时间帧不等于独立模型推理，这项证明不声称四次模型独立性。

旧七局的同帧合格花色来源回放 `replay-v30-physical-source` 为 7 局完成、0 未解决、0 异常；保留原来缺少独立花色/数量字段的 `replay-v30-original`，仍为 6 局完成、1 段未解决，不能混用结论。第一次单文件回放因未建立输出文件夹而未能保存报告，建立文件夹后正常重跑；这是运行准备错误，不是识别测试失败。

最新真实 session 全 4,751 帧的 `replay-v31-own-final-history` 为 1 局完成、0 恢复、0 未解决。SELF 历史现在为 27，事件数 38→39；逐项比较所有回调的时间、阶段、三家张数及剩余牌总数，与原始 v28 完全相同。修复只补了直接看清的自己的最后红王历史，没有改动外部扣牌。
