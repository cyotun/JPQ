# 用户需求与决策追踪 · v0.2.27

2026-11-12 对照本会话需求、现有文档及源码整理。这里记录**最终有效要求及其变化**，不是把所有历史建议都当作当前功能。产品细节以 [当前规格](design/current-spec.md) 为准；实现流程见 [逻辑手册](development/program-logic.md)，本轮验证边界见 [发布记录](releases/0.2.27.md)。路径均相对于 `JPQ/` 根目录。

状态说明：**已有实现**＝已定位实现及对应文档，不等于本轮重新通过真机或证明所有对局准确；**范围限制**＝仅部分条件可用或验证不足；**取消/替代**＝用户后续明确改变决定；**持续约束**＝以后每轮仍须遵守。

## 识别、复核、连续局与资源

| 编号 | 最终要求或决定 | 当前状态、实现与记录 |
| --- | --- | --- |
| R01 | 首家出牌后、中后盘或尾牌不能因“画面不完整”停记 | 已实现多帧/单家复核/恢复路径；记录为持续正确性要求，**不是已证明再无漏记** |
| R02 | 临时复核不显示问号，也不要常驻复核页；后台核好后再扣牌 | 最终决定取代早期全局异常页；`ConfirmedRoundPresentation`、`GradeCounterPresentation` 保持同局确认显示，不能把缓存回填为证据 |
| R03 | 不到整局结束不要因自己先出完停止 | 已分离 SELF_FINISHED 与 FINISHED；受限迟到自家末手仍可事务提交，队友视角继续处理三家 |
| R04 | 看见队友余牌后，显示池剔除队友牌，仅剩对手 | 已有完整手牌稳定确认与版本绑定；`RemainingPoolTracker`，不是把队友展示当一手已出牌追加 |
| R05 | 改隐藏/重置/三家设置不应破坏后续记牌 | 配置展示与账本分离；但切出游戏若形成真实不可见缺口仍须按缺口恢复，不能承诺错过牌后凭空补齐 |
| R06 | 发牌初始化和扣牌应快，尽量达到参考 APK 水平 | 保留为性能目标；已有模型预热、快路径及有界帧处理。没有覆盖所有设备的启动/延迟 SLA 或准确率证明 |
| R07 | 修复遗漏A、重复大/小王、三带二Q/J、大炸弹、尾局等具体反馈 | 已落入相关 proof、事件边界与队友确认回归；具体历史报告保留，不能只验证用户指出的一手而忽略同局其他手 |
| R08 | 切出游戏或开其他浮窗后要能恢复，下一局正常重启 | 已有可见性epoch、真实断点检查点和有限接收端修复；看不到的出牌不能猜，未核实原始来源仍保留 |
| R09 | 关闭/停止后系统共享必须一并停止，避免残留 | `CaptureService`/`CaptureLifecycle` 幂等清理；最近任务移除与按Home暂退须区分，系统停止回调也清资源 |
| R10 | 三家数量不能冻结而牌格继续扣；不能漏记重复同值牌 | 数量与详情来自已提交事件，使用独立数量来源和物理事件边界复核；数量不是另一份可随意补写的账本 |
| R11 | 临时弱读、数量OCR噪声不能耗尽整局证明 | 已有来源去重/矛盾隔离及 `commitAccepted`；先成功提交再消费，失败保留或重新取证，不复用旧票数 |
| R12 | 不得只隐藏异常提示来冒充正确，不能猜缺失的牌 | 持续约束；真实全桌缺口与单家歧义分别处理；FINISHED不自动证明完整 |
| R13 | 优化发热、耗电，同时保持记牌效果 | **待进一步量化验证**；源码有有界处理和模型约120秒空闲释放（GPU且屏幕非交互时延迟释放），不是普遍低功耗保证；当前FULL_CPU，没有目标设备功耗/温升基准或达标结论 |

| G08 | 不显示“未识别级牌，暂按天然同花顺判断”之类提示 | 已取消该提示；规则未知按天然构造证据及不确定性上界处理，不能写成确定没有逢人配 |
| S01 | 牌格旁小图案，协调灰底；亮为尚可能，暗为当前范围已排除 | 已选黑桃图案/16dp槽；不显示中文状态，不代表某家一定持有 |
| S02 | 2–A参与可行同花顺窗口时有金色字效果，不可能恢复白色 | 已选A金色字`#FFD04A`，取消薄荷字/其他方案；♥与大小王不高亮，候选是窗口点数并集 |
| S03 | 开局通常全亮，随出牌排除，不要错误中途亮回 | 依当前证据计算，不能硬编码“每局全亮”或暗后永久锁死；同局UNKNOWN通常保持上份显示，同一范围可接受保守收窄 |
| S04 | 同花顺必须记花色、计入变牌，未知池全排除才暗 | 四花色十个五张窗口、实体容量/红黑不确定分配/逢人配补位/每家容量统一求解；未知不是无可能 |
| S05 | 自己出完剔除队友牌后，同花顺也切到对手范围 | 同一队友牌池版本共享；重验期不发布混合三家池的临时金字。少于5张的各家不能组同花顺 |
| S06 | 原始规则未读到时不计算含变牌成顺 | 只以天然牌建立确定可行证明，未知替代仍可能留下UNKNOWN候选；自然范围排除不等于规则未知下全局排除，见逻辑手册 |

## 后续仍需明确保留的未完成项

1. 多游戏、其他玩法、大掼蛋各大厅入口及两种目标机型/系统组合的逐项适配和验收，不能只因为界面有入口就标完成。
2. 当前保留中断来源的真实历史仍有未核实部分；新的恢复代码不能代替缺失的牌面证据。
