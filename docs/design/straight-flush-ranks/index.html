同花顺候选点数提示

在牌格表头标出仍属于至少一个可行同花顺窗口的点数，帮助快速定位连续区间。保留现有悬浮条的两行高度、灰色牌格、黑金按钮和牌格旁小黑桃。

A · 柔和金色字

推荐

只改变可行窗口内的点数文字色。提示直接、安静，不影响数量、炸弹红色或零张暗灰数字的阅读。

B · 白字加细下划线

对照

点数保持白色，以表头底边的一条金色线表示候选。颜色更克制，但扫读时需要多注意牌格底部。

同一套判断：点数高亮与右侧小黑桃来自同一个“至少存在一个可行同花顺窗口”的状态，计算纳入剩余逢人配；红桃级牌格、大小王不参与同花顺高亮。

这里汇总整个剩余牌池的可能性，不表示某一家手里一定有这些牌。逢人配可补窗口缺位时，缺失点数也会标出；示例数字仅为演示，不声称牌局算法已完成。
