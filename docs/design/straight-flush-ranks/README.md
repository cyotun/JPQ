# 同花顺候选点数提示 · 设计确认稿

这是独立的交互设计预览。用户已确认采用 A 金色文字（`#ffd04a`），生产候选已接入，验收状态见 [0.2.17 记录](../../development/repair-0.2.17.md)。打开 [index.html](index.html) 即可离线使用。它沿用当前悬浮条的比例与黑金按钮、灰色渐变表头、两行牌格、红色炸弹数、暗灰零张数、红桃级牌首格、角标以及牌格旁 16dp 黑桃槽位。

页面以单列全宽展示两种高亮，方便直接看完整记牌条：

- **A（推荐）**：可行窗口里的普通点数以更醒目的金黄色（#ffd04a）显示。
- **B**：普通点数保持白色，只在表头底边加同色 2px 下划线。

顶部控件可以切换开局、中局、逢人配补位和全部排除四组示例，也能标记当前选中的方案；两种外观始终完整显示，且共用相同候选牌点和黑桃状态。示例中，中局及逢人配场景只保留 A2345；开局示例让所有普通点数都有天然牌，逢人配场景将 4 的数量设为零并注明由一张逢人配补位，说明高亮表示“逻辑窗口需要的点数”，并非余牌池中一定有天然的 4。

点数与右侧黑桃共用“至少存在一个可行同花顺窗口”的设计语义，检查范围纳入剩余逢人配。红桃级牌格和大小王不高亮。窗口采用 A2345 至 10JQKA；候选状态按整池可能性汇总，不代表任一玩家确定持有。这里的牌数和窗口是静态示例；生产候选另有完整窗口并集算法、4,096 组独立匹配校验与 Android 原生渲染检查。

字体通过相对路径读取仓库现有 `overlay.ttf`；若桌面浏览器不能读取仓库字体，则回退系统中文字体。页面和元素使用独立稳定标识 `jpq.design.straight-flush-ranks` 与 `jpq.design.straight-flush-ranks.*`。
