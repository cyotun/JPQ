# 记牌器 · 设计确认图 v3

2026-10-11。应用名已确定「记牌器」，JPQ 为工程代号。手机 App 尚未开发；以下为自绘静态设计，牌局/版本/下载大小均是示例。

保留原 APK 字体、色值、渐变表头、细边框与紧凑行距，以及取消手动改牌、Cloudflare 更新等已确定范围。本次新增两个独立设置：「显示重置按钮」默认开，「双击记牌条隐藏」默认关。开启双击后移除隐藏圆钮，隐藏后仅出现显示圆钮，点击恢复后它消失。按钮移除不留空位、不放大牌格。

需要确认的新增交互集中在四项：

1. 移除商业栏目，首页/底部保留记牌与设置。
2. 按钮默认保留，可按已确认要求移除；长按记牌条内容区或可见隐藏按钮进入工具，拖动内容区移动，不触发双击。
3. 冲突自动复核；不可恢复时停止精确显示并等待下局，不设置手动改牌。
4. 每日自动检查，空闲时 Wi-Fi 自动下载，记牌结束后提示安装。

完整规格见 [PRD v3](../PRD.md)，实际字体/配色证据见 [样式研究](../../research/display-style.md)。全自动逐手零错漏是验收门槛，尚无准确率实测结果。旧稿可从 Git 历史追溯。用户已确定本次按钮开关与双击逻辑；其余新增操作和整体设计确认后才进入 Android 开发。
