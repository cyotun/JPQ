# 当前产品与界面规格 · v0.2.26

2026-10-19 稳定基线。本文整合已确认设计与当前实现，覆盖早期 PRD 中冲突的交互；没有提出新的 UI 改动。版本和实测范围见 [发布说明](../releases/0.2.26.md)。

## 支持范围与页面

应用名「记牌器」，黑金牌面图标。当前可用组合为腾讯「大掼蛋」独立 App、掼蛋默认、四人、两副牌；其他游戏/玩法保留扩展位置并禁用。总数 108，普通点数各 8，大小王各 2；不提供任意改牌库来修正识别。

| 页面 | 行为 | 源码入口 |
| --- | --- | --- |
| 记牌 | 平台、玩法、人数、副数和牌库分区；底部大按钮，目标设备单页展示；无营销区域 | `MainActivity.home/render`、`HomeGameCatalog` |
| 开始/停止 | 开始申请系统共享，成功后按钮为停止；取消授权不伪装启动，停止释放采集和悬浮窗 | `MainActivity.startCapture/stopCapture`、`CaptureService` |
| 设置/权限 | 底部仅记牌/设置；权限入口在设置，授权返回复查状态、返回原页面；无长按悬浮设置 | `MainActivity.settings/permissions/navigate/leave` |
| 尺寸/牌序 | 横屏示例预览；八项尺寸参数、牌序拖动；保存、退出、恢复默认 | `MainActivity.size/order`、`ConfigStore` |
| 牌局与诊断 | 最近牌局、导出、本机诊断开关、清理集中在二级页；停止记牌后可导出完整 ZIP 或清理本机记录和诊断画面 | `MainActivity.diagnostics`、`RoundRepository` |
| 更新/备份 | 正式基线保留原更新入口；BETA 新版按用户要求改为一级设置最右侧单按钮，见 [应用更新行](inline-updates.md)；配置导入导出、系统安装确认保留 | `UpdateManager`、`ConfigStore` |

## 悬浮条

灰色渐变表头、连续深灰底、细黑边和金色按钮，使用本机准备的指定字体。点数/数量默认等视觉字号，10 不缩小且完整显示。同花顺槽底色连续，图案垂直居中。参考 [显示研究](../research/display-style.md) 和 [参数说明](history-width.md)；生产浮点默认值以 `DisplayConfig` 为准。

- 普通数量 ≥4 标红；大小王各自 ≥2 标红；其他正数白色，0 淡灰。沿用参考软件阈值，不要求组成完整王炸。
- 级牌数字右上金色三角，不遮数字；♥首格在大小王之前，单独统计红桃级牌；普通级牌列不重复计入同一张红桃级牌。
- 三家区域：隐藏、仅累计已出数量、数量和具体明细。上/对/下黄色格为已出张数，不是剩余张数；关闭不停止后台记账。
- 明细用紧凑点数串和 `·` 分隔，10 为一个点数，JJ 表示两张 J；“不出”不计入。
- 明细区默认约 320dp，超过后按真实文字宽度扩展并留少量尾边；同局只扩不缩，新局恢复。屏幕宽度不足时保留可显示的完整牌组，不无限缩字。
- 重置按钮可关闭。默认隐藏圆钮；开启双击隐藏后移除圆钮。隐藏仅留「显示」，后台继续；显示按钮可拖动，拖动不触发恢复，单击才恢复。
- 展开条可拖动，长按不弹工具。游戏位置持久化，重启采集恢复上次位置；旋转/可用范围改变时换算并夹取边界。

入口：`OverlayController`、`DisplayConfig/HistoryWidth`、`OverlayPositionMemory`、`ConfigStore`，具体路径见 [架构](../development/architecture.md)。

## 牌局与静默复核

启动先显示两行金色等待条，取得合格新局基线后切换牌格；中途启动且缺开局证据时，不补猜此前历史。

同局动画、空帧、花色待确认、队友视角切换或暂时冲突均在后台复核。**已确认计数和历史保持，不切换问号或常驻“正在复核”页；证据充分后再提交扣牌。** 暂留值不是新牌面/数量证据。真正的停止、采集失效和新局边界分别处理。

自己出完后继续记三家；确认队友手牌后从未知池剔除，使显示只剩对手牌。队友牌池重验时保留上一份确认显示，避免临时恢复混合三家池。只有充分的结束证据才结束本局，“头游”“队友手牌”不直接视为整局结束。

## 级牌、逢人配与遮挡

按当局彩色我方/对方面板及合格牌面标识确认级牌，灰色面板不作本局依据。确认后按本局保存，暂时 OCR 失败不撤回；新局重新确认，不能无证据沿用上一局。

红桃级牌为逢人配，可代王以外的牌组成牌型；单出是普通级牌。扣实际物理牌，不扣其代替的逻辑点数。未确认级牌时同花顺只算天然窗口，不显示额外“未识别级牌”提示。

存在可信级牌区域且当前条确实重叠时，才显示「级牌区域被遮挡，请挪开记牌器」；不能因 OCR 失败就报遮挡。独立小提示放在条下，与牌格主体对齐；「一键挪开」金色实底，「忽略」另列。

忽略属于采集会话，跨局不重复，停止后重新开始才重置；设置可整体关闭。移开后提示消失。一键挪开只选顶部可容纳的安全位置，不自动挪至出牌区；无安全位置则保留手动处理。提示自身也进入真实遮挡 mask，不伪装为空桌面。没有采用条内提醒或单应用共享的新交互。

入口：`GradeSourceReader/TencentHudPanels`、`GradeCardCounter/GradeCounterPresentation`、`GradeOcclusionSession/Geometry`、`OverlayController`。

## 同花顺图案与候选字

采用 [A 金色文字](straight-flush-ranks/README.md)，普通点数表头 `#FFD04A` 表示至少参与一个尚可行窗口，无候选恢复白色；♥和大小王不高亮。图案沿用黑桃及连续灰底；暗色表示当前范围已排除，亮色表示尚未排除，不等于某家一定持有。

恰好五张同花连续点数，窗口 A2345…10JQKA，A 仅在两端。确认红桃级牌后可补缺，不能代王。保留花色和实体证据，扣自己初手、已出牌和确认队友余牌，结合每家容量排除。图案和候选表头共用结果。

局中 UNKNOWN 保持上份确认显示；队友牌池暂时重验不发布混合池金字。新完整证据仍能更新，不能把暗色永久锁死。规则范围变化、新局等待时清旧缓存。花色不确定不能作为“已不存在”的依据，具体算法见 [架构](../development/architecture.md)。
