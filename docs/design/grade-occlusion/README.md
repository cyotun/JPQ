# 级牌遮挡提示 · 已确认并接入

2026-10-14。用户已确认本页样式和交互，0.2.12测试版已接入 APP。[交互预览](index.html)与[三种状态效果图](grade-occlusion-preview.png)保留为设计依据，图为自绘示例，原型不是Android截图。

## 已接入的交互

- 记牌条下方增加小号黑金提示，默认开启，不弹窗、不主动移动。
- 遮挡时显示「级牌区域被遮挡，请挪开记牌器」，提供小号金色「一键挪开」和「忽略」。仅当顶部右侧的安全空位能容纳整条时允许一键移动，目标避开三家出牌区、本人手牌和需要读取的级牌区域。不会改变统计数字或重启牌局。
- 用户点击后整条移动，遮挡提示消失。没有安全空位时改为「请手动拖动」，使用原有的拖动行为。预览中的手动拖动范围限制在桌面顶部以演示这一退路，不代表改变 APP 的现有拖动范围。
- 点击「忽略」后，本次记牌会话不再显示遮挡提醒，即使区域改变或进入下一局也不恢复。只有停止记牌后重新开始，才清除本次忽略状态。
- APP 设置增加「显示级牌遮挡提示」，只关闭提示，不停用级牌读取。

点“恢复示例”重置设计演示。预览提供“顶部空间不足”，验证一键按钮不会把整条移到放不下的位置；“停止记牌／开始记牌”“模拟下一局”和“模拟区域变化”用于核对忽略状态的作用范围。停止后重启不会改变全局提示开关。移动、忽略、状态切换均保持示例牌格与三家数量不变。仅展示自绘的游戏背景与虚构牌局，不使用或修改用户提供的截图。

## 确认范围

用户已确认：遮挡提示的样式和文案、默认开启及全局设置开关、“一键挪开”的安全位置/空间不足退路、仅持续到本次停止后重启的“忽略”。没有“未识别级牌”的悬浮提示。实际提示为32dp高的独立小窗，单独屏蔽它的像素，不暂停记牌；安全顶部位置不足时保持手动拖动。已有位置记忆、牌格、数字和拖动方式继续沿用。
