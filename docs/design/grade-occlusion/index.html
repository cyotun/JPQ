级牌识别持续运行（示例）；提示开关只影响这行提醒。

遮挡时显示「级牌区域被遮挡，请挪开记牌器」，提供「一键挪开」和「忽略」。一键挪开会把整条移到顶部右侧可容纳的空位，提醒消失，数字保持不变。也可手动拖动；键盘方向键可移动本预览。

只有安全位置能容纳整条时才提供一键移动；空间不足时显示「请手动拖动」。不会自动跳动，也不会把一键目标放在三家出牌区或自己手牌区。

「忽略」持续到本次记牌结束；即使进入下一局或级牌区域改变，也不会再次提醒。只有停止后重新开始记牌才恢复提醒。全局提示开关单独保存，关闭提醒不关闭级牌读取。
