## 确认样式与含义

剩余牌格右侧显示 **12dp 单个小黑桃，含留白总宽16dp，无底框、无中文**。上半部延续表头灰色渐变，下半部与数量行同为 `#434343`。沿用记牌条两行高度，不弹出面板；关闭三家记录后仍可显示。设置中默认开启，可单独关闭。

图标默认亮金色，含义是“尚未排除同花顺”，包括信息未确认的情况；只有所有与已确认牌面、物理牌容量和当前变牌规则相容的天然与含变组合都排除后，才变为暗灰色。亮色不代表某一家确定持有同花顺。这里统计的是三家共同的余牌池，无法获知三家各自的完整分配。

## 判断方案与实现依赖

1. 按108张物理牌建立约束，普通牌每个点数/花色各2张。去除本人初始27张手牌和三家的真实已出牌；自己的牌打出后不能再扣一次，自己出完后展示的队友手牌不能替代本人初始牌。记录物理花色及证据来源，红黑不等同于红桃/黑桃。
2. 读取当前房间的有效变牌规则和实际手牌变牌标记，普通掼蛋的红桃级牌可配任意普通牌。双级牌等变体需独立确认，不能把HUD显示的两队级数直接当作两个变牌点数。尚未确认规则时保留亮色。
3. 对四种花色分别枚举五张、同花色、连续点数窗口：A2345至10JQKA。不允许QKA23等跨尾环绕，算法顺序独立于用户设置的显示牌序。
4. 天然组合要求窗口每个点数至少有一张未耗用的同花色牌。含变组合明确选取互不重复的物理变牌补空位；同一张红桃级牌不能同时当本牌和另一个位置的变牌。实际物理变牌与出牌界面的替代点数无法确认时保留不确定性。
5. 红黑或变牌身份不完整时枚举与证据一致的可行分配。只要任一分配仍可成顺，或当前证据无法排除含变组合，就保持亮色；只有全部排除才变暗。
6. 独立读取已定位牌角的花色，不延长主记牌提交的阻塞路径。只有稳定证据更新消耗牌约束，不让动画、短暂闪色或显示队友手牌制造错误的“无”。覆盖天然/含变/自然级牌与替代冲突/多张变牌/全部排除/未知花色/队友视角/双级规则等检查；真机完整牌局验收另行记录。

规则参考：[国家体育总局刊载的淮安掼蛋规则](https://www.sport.gov.cn/n20001280/n20745751/n20767274/c22011669/content.html)说明同花顺限五张同花色连续牌；[东南大学比赛规则](https://xxgk.seu.edu.cn/_upload/article/files/44/c8/f455e1d04d2a998e40454931740a/4f853bb4-29b9-45dc-9c56-7627ed4c9726.pdf)列出A2345、10JQKA边界和红桃级牌配牌。发布者的[《掼蛋入门到精通》红桃级牌章节](https://s.zhangyue.com/read?anchorId=&bid=13354586&cid=9)包含一张、两张红桃级牌配同花顺的示例。这些用于规则核对，不冒充腾讯具体房间的规则验证结果。
