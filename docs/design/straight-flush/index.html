同花顺提示 · 牌格旁图案版

基于三家剩余的未知牌池判断“仍有可能”，包含变牌的补位组合。沿用原黑金字体、灰牌格和两行高度。这里使用示例牌局，尚未接入 APP。

紧贴剩余牌格 已选位置

单个12dp小黑桃，无底框、无文字，含留白总宽16dp：亮金色表示仍可能有，暗灰色表示已排除；未知暂不显示。关闭三家记录时依然可见，不增加高度，不弹出面板。

B · 放在记牌条最右端

同样不增加高度；记录变长时标识会随末端移动，视线距离更远。

C · 剩余牌格下方文字条

占用更少宽度，但增加约 16dp 高度，遮挡区域比前两种更大。

统一的四种状态

同花顺可能

不使用变牌，余牌池仍可成顺；也检查所有含变组合。

同花顺需变

天然成顺已被排除，但加上剩余变牌仍可组成。

同花顺无

所有花色和含变组合都已排除后才显示。

同花顺待确认

未确认花色、级牌或变牌；不会用“无”代替未知。

示例：打 3 时，♠7、♠8、♠10、♠J 加 ♥3，可补成 ♠7–J。同一张 ♥3 只能占一个位置；组成红桃顺子时也不能同时充当本牌和变牌。不同玩法分别读取有效变牌规则。

“可能”不代表同一家一定持有。原点数模型仅区分红黑；实现时需要另加花色识别和级牌规则确认，未知期间显示“待确认”。设置中提供显示开关，当前预览不改变实际记牌功能。
