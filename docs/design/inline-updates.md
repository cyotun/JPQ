# 设置首页的应用更新行

2026-10-24，按用户要求将应用更新操作移到一级设置最右侧；不再进入更新二级页面。此改动先在记牌器BETA 验证，正式版验收发布前保持原包。

更新行沿用设置中的深灰圆角底色。左侧为「应用更新」和较小的状态文字，最右侧保留一个金色按钮；整行没有箭头、没有点击跳转。按钮随更新状态变化：

| 状态 | 右侧按钮 | 行为 |
| --- | --- | --- |
| 未检查、已是当前版本或需重新检查 | 检查更新 | 后台获取并验签最新正式清单 |
| 检查进行中 | 检查中 | 禁用，防止重复提交 |
| 已确认有新版本 | 下载 | 原地下载，非 Wi-Fi 时确认流量使用 |
| 下载进行中 | 下载 N% | 显示进度并禁用 |
| 已校验的安装包准备好 | 安装 | 后台复核后打开 Android 安装确认 |
| 安装包复核进行中 | 校验中 | 禁用 |
| 正在记牌 | 记牌中 | 不提供手动更新操作，停止后恢复 |
| 当前为 BETA 且无独立更新通道 | BETA | 禁用；不读取或安装正式通道 |

暂停或临时下载失败后可在原位置重试。旧版本下载地址失效时先恢复为检查更新，不能在无效版本上反复下载；缓存失效或安装校验失败时也回到明确的下一步操作。安装仍需系统授权和确认，不绕过未知来源权限。

下载完成通知直接进入设置首页。旧通知或保存状态携带 `page=update` 时也兼容映射到一级设置。返回键从设置回到记牌首页，不再经过更新页。

页面只读取更新状态缓存，验签、整包哈希和下载在后台执行；设置处于前台时刷新进度，页面暂停或退出后停止界面轮询。BETA 与正式包身份、签名及发布隔离遵循根目录 [项目规则](../../AGENTS.md)。
