# 记牌器首页设计确认原型

这是对用户指定原 APK 首页截图的黑金风格重排。用户已确认最新布局，Android 0.2.15 已接入对应原生页面和悬浮条，真机视觉检查待执行。当前主流程是大掼蛋（腾讯）→ 掼蛋默认玩法 → 4 人 → 2 副；其他游戏、玩法、人数与副数展示为禁用的扩展位置。

原型保留模板设备壳、设备切换、实时状态栏、键盘和底部安全区。应用标题为「记牌器」，底部只有「记牌／设置」。没有会员、充值、广告或客服区。首页内容与底部开始按钮分层布局，目标为一页展示。

## 预览

本地开发服务的根路径 `/` 为记牌页，服务本次使用 `http://127.0.0.1:4175/`。其他状态均在同一个根路径内呈现，不引入额外路由。主代理负责在 Codex 内置浏览器做视觉与交互验收。

页面外侧有原型说明。点击「开始记牌」只切换示例状态为「记牌中」和「停止记牌」；不调用屏幕共享、录屏、Android、游戏或任何后端。

## 交互覆盖

- 「＋」和已选游戏平台打开模板 BottomSheet。搜索使用 KeyboardInput，原生模板键盘随焦点显示；选取大掼蛋后关闭搜索与键盘。
- 未适配的游戏和玩法禁用。移除已选游戏后，开始按钮禁用；重新选择大掼蛋即可恢复。
- 点击开始后切换为停止，配置暂时锁定；点击停止恢复配置。停止状态在设置与记牌 tab 切换时保留。
- 三家出牌显示可设为关闭、仅数量或数量和明细，记牌页与预览页均同步改变样式。其他设置用本地开关示意，并在预览摘要中显示当前选择，不代表已执行手机功能。
- 点击「预览」查看悬浮条示例；所有牌数与出牌文字均为固定示例。
- 牌局和诊断功能集中在设置中的二级 sheet；本原型没有读取或生成真实诊断文件。
- 设置中的「应用更新」入口保留；原型只展示入口，不访问更新服务器。
- `public/grade-counter-preview.html` 是独立横屏样式说明板，首页仍使用模板运行环境。♥在鬼牌前，当前级牌右上角金色三角，10 与其他点数等字号，计数与标题等字号，同花顺沿用已确认图案与连续灰底。

## 浏览器验收建议

1. 默认 iPhone 查看完整首页，确认没有纵向滚动、文字截断或内容盖住开始按钮。
2. 切换 Pixel 10，确认模板状态栏、设备壳、相机孔和导航条保持完整，首页仍无需滚动。
3. 添加游戏 → 搜索「大掼蛋」→ 选取，随后再打开搜索没有结果的内容，确认空状态和完成按钮。
4. 移除游戏 → 关闭 sheet → 确认开始禁用 → 添加大掼蛋，确认恢复。
5. 开始 → 切换设置 → 返回记牌 → 停止，确认按钮与配置锁定正确。
6. 设置分别选择三种记录显示方式，返回记牌并打开预览核对三家列。
7. 核对控制台无错误、稳定页面标识没有重复，iPhone/Pixel 切换不丢失应用示例状态。
