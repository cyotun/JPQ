2026-10-11，修订 v2。应用名称已确认「记牌器」，JPQ 为工程/仓库代号。当前仍在设计确认阶段，手机 App 和自研 APK 尚未交付。

完整规格以 [PRD v2](design/PRD.md) 与 [四张设计图](design/review/README.md) 为准。本次依用户指令删除手动纠错、补记、撤销和初始手牌编辑；用户明确保留 Cloudflare 应用自动更新。用户已选定 [1 号黑金牌面图标](design/icons/README.md)，其余三个候选一并留档。

## 2. 当前使用设计

首页保留原「平台 → 玩法 → 人数 → 副数 → 牌库 → 开始」纵向顺序；默认大掼蛋、掼蛋默认、4 人、2 副。只开放已适配组合，标准 108 张牌库可查看，首版不允许随意修改牌库后继续宣称标准记牌。

使用流程：开始记牌 → 系统共享授权 → 返回大掼蛋 → 等待发牌和贡牌结束 → 完整基线自动校验 → 记牌。中途启动等待下一局，不提供人工补齐。正常初始化无手牌确认页。

等待提示：

> 进入游戏房间后，会自动开始记牌
>
> 牌局已开始仍未显示？请检查权限或重新开始记牌

正常悬浮条：隐藏圆钮 + 15 列牌面/剩余数量 + 上对下三行历史 + 重置圆钮。黄色数字表示累计已出，历史使用紧凑牌组与 `·` 分隔，超长历史展示最近部分，完整账本保留本地用于验证。没有常驻第三按钮。

隐藏仅留「显示」圆钮，采集继续。关闭三家区域时保持左侧牌格/字号并收缩窗口，不留不可见触摸占位；完整和仅计数分别记宽度，隐藏的右侧调整值保留。工具仅有两页调整、三家开关、重置和停止，不含改牌入口。

「尺寸调整」「牌序调整」保留原两个标签、上方预览、下方调整、退出/重置/保存并退出。宽轨道、竖条滑块和 8 + 7 两行牌块按参考截图复现。默认值与参数精度见 [原默认参数](research/reference-display-defaults.json)。尺寸保存基线为人数/副数，牌序按游戏/玩法，拖动仅改变显示顺序。

悬浮条字体已核实为钉钉进步体，官方字体与 APK 字体 SHA-256 一致。本轮重画采用此字体，主底色 #262626、牌格底 #434343、金色 #FFE395；详见 [样式证据](research/display-style.md)。旧版功能汇总图不再作为当前界面规格。

## 3. 自动准确记牌

```text
剩余[r] = 完整牌库[r] − 自家初始手牌[r] − 其他三家已出[r]
```

标准初始化后合计 81；自家打出的牌不再扣一次。贡牌属于转移，基线在其完成后建立；自家出完显示队友手牌，不替换自家初始基线。物理点数与万能牌的逻辑替代点数分开。

多帧牌面、各家区域、回合边界、余牌变化和自己的手牌变化共同验证事件；同牌组第二次出必须识别为新事件，长时间停留只记一次。数量守恒不能单独证明识别正确。

冲突先自动重读已采集画面。证据不足或漏采集无法恢复时，停止本局精确数字显示并等待下一局，不猜牌、不把负数截成 0、不要求用户修正。异常恢复是防止误导，不能代替稳定记牌验收。

两部手机各至少 10 局，并覆盖所有目标模式和特殊阶段，逐手对照独立真值；任何错记、漏记、无法确认或非预期中断算失败，修复后回归。实际正确率尚未测得，不以有限测试承诺未来所有版本永远无误。

## 4. 本地、权限与更新

必要流程包括系统屏幕共享、悬浮窗、采集前台服务与通知；后台耗电/锁定按澎湃系统实际状态引导，不能查询的项明确需手动设置。适配基于采集画面和窗口几何，处理旋转、分辨率、安全区和单应用共享。锁屏/共享失效不继续显示过期精确数字。

配置存储与导出包含尺寸、牌序、三家开关、位置与更新偏好；不备份授权 token、密钥、截图和账本。事件默认保留当前及最近 20 局；诊断截图用户主动打开后限额保存，短时自动复核帧缓冲只在内存使用。

独立 Worker `jpq` 已部署，地址 [jpq.240438457.workers.dev](https://jpq.240438457.workers.dev)。Workers Free，无 APK 存储绑定和发布包，尚不能下载安装自研 App。更新不上传游戏画面、不改其他项目、不自动启用付费套餐。

D4 建议每日检查一次、空闲时 Wi-Fi 下载、结束记牌后提示安装；系统要求确认时走官方界面。校验清单与 APK 身份，失败保留旧版本；断网继续记牌。完整协议见 [更新方案](design/cloudflare-update-plan.md) 与 [签名下载契约](design/update-contract.md)。

## 5. 研究与后续确认

已做 APK 静态检查、自动反混淆、核心方法阅读和随包业务/预处理 Lua 的本地解密与校验。可阅读的方法并不等同完整原始工程；尚未验证参考模型推理、最新游戏配置和真机效果。证据见 [APK 研究](research/apk-analysis.md)、[方法研究](research/method-analysis.md) 与 [GitHub 调查](research/github-survey.md)。参考 APK/模型/脚本与字体二进制不进入源码仓库，发布资产需有可再分发依据。

待确认的交互保持 D1–D4 编号：D1 只保留记牌/设置栏目；D2 长按隐藏打开工具、条内空白拖动；D3 自动复核和不可恢复异常的显示；D4 自动检查/下载/安装时机。取消纠错、保留应用自动更新和应用名称已确定，不重复征求确认。

设计确认后按 [技术方案](design/technical-plan.md) 与 [验收里程碑](design/acceptance-plan.md) 进入开发。读取两部手机实际 Android API、大掼蛋包名/版本及连续牌局样本是实现后的验证输入。
