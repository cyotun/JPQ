## 功能基线

- 腾讯大掼蛋默认四人两副牌；黑金首页、开始/停止和单一权限入口。
- 本地牌面/OCR/花色识别、多帧确认、去重与静默复核；保留已确认显示，充分确认后扣牌。
- 自己出完后继续队友视角，确认余牌后剔除；末手交接晚到证明与事件原子提交。
- 级牌三角、♥独立逢人配、同局计数显示保持、彩色面板判定和会话级遮挡忽略。
- 同花顺考虑花色、逢人配和每家容量；图案与金色候选字同源。暂时重验不发布错误混合池金字。
- 尺寸/字号/牌序、三家显示三模式、重置显示、双击隐藏、可拖动显示按钮、位置持久化。
- 本地牌局诊断二级菜单、配置备份和应用更新入口；服务器仅更新。

本次相对早期 GitHub 提交也归档了 0.2.20–0.2.25 的恢复、物理身份和生命周期修复；详见对应 `repair-*`。完整规格和入口见 [当前规格](../design/current-spec.md)、[架构](../development/architecture.md)。
